# Исследования и зафиксированные результаты

- `forecast/`: протокол выбора прогноза, rolling-проверка, замороженный выбор,
  финальная оценка. `rolling-f4.json` сохранён побайтово; его SHA проверяется тестом.
- `response/t6/`: исследование наблюдательного отклика T6/F9 и ограничения методики.
- `data/`: профили исходных данных, справочник тегов и реестр исключённых периодов.
- `results/`: фиксированные исследования стратегий и агентного протокола.
- `experiments/`: исходный журнал сценарного исследования.
- `validation/`: срезы до/после изменения профиля тяжести 22.09.2026.

Исторические результаты не пересчитаны при переносе из рабочего каталога.
Пути к публичным материалам обновлены; локальный абсолютный путь в реестре
исключений заменён на `task`. Исходные данные организаторов в репозиторий не входят;
для повторных расчётов необходим каталог `task/`, описанный в корневом README.

Тесты вызывают настоящий код и сравнивают результат с фиксированными эталонами.
Компактный эталон benchmark находится в `tests/fixtures/evaluation/`.
Обновление эталонов требует объяснения изменения методики или поведения.

Вспомогательные `response/common.py` и `response/final/{response_model,fcommon}.py`
восстановлены без изменений из родителя `1dde0b6`: прежняя чистка удалила их,
хотя исследование T6 и сравнение с T11 продолжали их импортировать.
`response/final/` — исторический вариант T11, он не используется продуктом.
