# Product

## Реализованный демонстрационный контур (21.09.2026)

Экран запускается локально командой `uv run neftecode serve` и получает SSE-поток
`/api/stream`; условия теперь являются узлом 00 в той же схеме, а ответ оператору
отображается перед раскрываемыми доказательствами. Режимы live, offline/fallback и
локальный replay последнего успешного прогона подписываются по фактическому payload.
Replay не импортирует архив и не является новым расчётом.

`uv run neftecode-stack` — отдельный сервисный запуск для `/v1/*` и legacy
`/api/decide`: его gateway не поддерживает `/api/stream`, поэтому не следует обещать
ему покадровую демонстрацию frontend. Это прототип советчика, а не контур управления.

## Users

Оператор установки НПЗ (АВТ → гидроочистка → блендинг дизельного топлива) и его технолог.
Ближайшая реальная аудитория — эксперт жюри на защите «Нефтекод 2026»: смотрит экран
с проектора десять минут, решение с живой моделью длится 2–4 минуты. Ему нужно за один
прогон увидеть маршрут расчёта, поверить числам и понять, что LLM-агенты действительно
работают, но не управляют ограничениями.

## Product Purpose

CUTPOINT — советчик оператора: по срезу телеметрии на момент t строит план на 3 часа,
проверяет его жёсткими ограничениями (Gate), даёт агентам сузить выбор и выдаёт один из
трёх исходов: hold, recommend_scenario, refuse. Отказ — полноценный результат, а не сбой.
Успех интерфейса: за один прогон зритель понимает, откуда взялось каждое число и на каком
этапе система отказала бы, если бы данных не хватило.

## Brand Personality

Инженерный, немногословный, честный. Три слова: спецификация, схема, выдержка.
Интерфейс — технологическая схема установки, а не витрина: каждый элемент отвечает
на вопрос оператора; чего нет в данных, того нет на экране.

## Anti-references

- SaaS-дашборды с KPI-плитками, градиентами и «AI»-свечением.
- Восемь разноцветных пастельных подложек по этапам (отвергнуты руководителем).
- Фальшивые терминальные логи, печатающийся текст, частицы, бегущие по стрелкам.
- Кинематографичная хореография загрузки; анимация, которая не означает смену состояния.

## Design Principles

- Честность выше красоты: оговорки происхождения чисел и «модель не участвовала» неприкосновенны.
- Маршрут виден до результата: схема всего расчёта показана до нажатия «Пуск».
- Работа системы — это содержание: время, счётчики и решения агентов показываются по ходу,
  а не пересказываются после.
- Один акцент означает «сейчас»: цвет получает только текущий шаг и слой агентов.
- Монохром несёт иерархию: рамка, начертание, плотность — вместо цветовых полос.

## Accessibility & Inclusion

WCAG AA (контраст ≥ 4.5:1 текст, ≥ 3:1 крупный текст и рамки состояния) считается
цифрами, не на глаз. Состояние никогда не передаётся только цветом: у каждого — свой
стиль рамки и слово. Полная работа с клавиатуры, `prefers-reduced-motion` даёт
мгновенные переходы без потери информации. Чёрно-белая печать сохраняет смысл.
