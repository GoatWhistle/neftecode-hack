# Response layer поверх production forecast

Поручение пользователя 2026-09-15: взять существующий прогноз F(state) ровно с текущей логикой доверия и запасной модели,
не заменять его baseline модели отклика, добавить только найденный эффект β_τ·ΔT, проверить композицию F + β_τ·ΔT,
отдельно откалибровать итоговую неопределённость относительно ЛИМС без утечки и описать интерфейс слоя.
β не переоценивается, новые модели не ищутся.

## Правило, зафиксированное до запуска

### Компоненты
- **F(state)** — production: `build_features` на момент t → `DataTrustAgent(bundle.config)`; нет пригодного источника →
  прогноза нет; ПАК непригоден → `bundle.fallback` (`catboost_no_pak`), иначе `bundle.selected` (`last_pak`);
  значение `predict_candidate`. Модель — `artifacts/model.pkl` без переобучения.
- **β_τ, β_weak, β_strong** — `response_model.fit(frame, rows, τ)` из `context/response-research/final/response_model.py`
  без изменений; τ — первое число месяца момента t; процедура fit та же, что в спецификации (ежемесячно).
  Зоны применимости — `response_model.predict(art, live_state(t), ΔT)`; зона C — эффект не применяется.
- **Композиция:** `S(t+h | ΔT) = F(state_t) + β_τ · ΔT`.

### Как проверяется композиция на истории
- Цель — лабораторная сера ГО, точка 2. Моменты решения t = отбор − h, h = 3 ч (основной: β описывает плато отклика
  3–8 ч) и h = 2 ч (горизонт обучения F; эффект за 2 ч может быть доставлен не полностью — чувствительность).
- Исторического «предложенного» ΔT нет, поэтому для проверки берётся **реализованное** изменение
  ΔT_real = среднее T11 за (t+h−30 мин, t+h] − среднее T11 за (t−30 мин, t]. Оно используется только оценщиком.
- Периоды: 2025-07-01…2025-12-31 (диагностика; F на нём вне обучения catboost, радиус F калибровался на нём)
  и 2026 (оценка; уже просматривался).
- Метрики по периоду и горизонту: MAE F и MAE F + β·ΔT_real на всех, спокойных (|ΔT_real| < 0.25),
  с действием (|ΔT_real| ≥ 0.5 и ≥ 1); наклон калибровки: OLS (y − F) = a + s·(β·ΔT_real) на строках |ΔT_real| ≥ 0.5,
  бутстреп 1000, seed 20260915. Композиция согласована, если s в разумной окрестности 1 и MAE на действиях не хуже F.

### Калибровка итоговой неопределённости относительно ЛИМС
- Остаток композиции r = y − (F + β_τ·ΔT_real).
- Для месяца m: калибровочные строки — пробы с отбором в (m − 6 мес., m − 4 ч] (результат ЛИМС уже доступен к m,
  ΔT_real вычислен по T11 до момента отбора ≤ m); β для каждой строки — артефакт её собственного месяца.
- Квантили без симметрии: q_lo = q0.05(r), q_hi = q0.95(r) — номинал 90%.
- Итоговый интервал для месяца m и предложенного ΔT:
  `lower = F + min(β_weak·ΔT, β_strong·ΔT) + q_lo`, `upper = F + max(β_weak·ΔT, β_strong·ΔT) + q_hi`;
  при ΔT = 0 — `[F + q_lo, F + q_hi]`. Для проверки подставляется ΔT_real.
- Отчёт: покрытие и ширина на всех / спокойных / с действием, recall и ложные тревоги верхней границы относительно
  предела 10; для сравнения — собственный интервал F из production.

Скрипт — `experiments/response_layer_2026-09-15.py`, результат — `experiments/response-layer-2026-09-15.json`.

## Результат

Коммит правила `3c44bd4`; данные — `experiments/response-layer-2026-09-15.json`.

**Воспроизведение F.** На 249 пробах 2026 года из `artifacts/predictions.csv` F(state) совпал с production до 1.8e−15

### Выводы

1. **Композиция согласована, но слабо идентифицирована на ЛИМС.** Добавка β·ΔT уменьшает MAE во всех четырёх
   срезах; на спокойных строках не меняет прогноз; на |ΔT| ≥ 1 при h = 3 ч в 2026 — с 1.831 до 1.649. Наклон s
   0.53–0.79, в трёх срезах из четырёх CI накрывает и 0, и 1; только 2026 h3 значимо > 0. Эффект по знаку подтверждается
   лабораторией, по величине скорее не завышен сильнее чем вдвое — это совпадает с тем, что β_weak = 0.5·β.
2. **h = 3 ч лучше h = 2 ч** для композиции (наклон и выигрыш на действиях), что согласуется с плато отклика 3–8 ч.
3. **Откалиброванный по ЛИМС интервал близок к номиналу:** 0.88–0.89 на всех строках при цели 0.90 и уже
   production-интервала на 20–25% (5.1–5.9 против 7.0–7.3 мг/кг); на строках с действием недопокрытие 0.84–0.88.
   Интервал несимметричен: в 2026 ЛИМС систематически выше F (q_hi ≈ +3.5, q_lo ≈ −1.8).
4. **Для предела 10 мало что меняется:** recall верхней границы 0.93–0.96, ложные тревоги 0.84–0.90 — у production те же
   порядки. Шум лаборатории около предела не устраняется ни одним слоем.

### Ограничения
- ΔT_real — реализованное изменение T11 вместе с реакцией APC, а не предложенная устойчивая уставка.
- Смысл T11 как температуры входа реактора не подтверждён: эксперт в сообщении 520 назвал T11 массовым расходом сырья.
- Строк с действиями 42–96 на срез; 2026 уже просматривался.

## Интерфейс response layer

```text
ResponseLayer.compose(forecast, response_state, delta_T, horizon_h, response_artifact, calibration) -> ComposedForecast

forecast: LiveForecast                    production F(state) без изменений: value, model (last_pak | catboost_no_pak),
                                          available, reason. Доверие и запасная модель решаются до слоя.
response_state                            response_model.live_state(t): PAK30m, PAK24h, PAK24h_cov, pak_frozen_now,
                                          T11, T11_30d, F26, h2oil, run_past12h — только для зон, в значение не входит.
delta_T: float, °C                        предложенное устойчивое изменение уставки температуры входа реактора ГО,
                                          удерживается ≥ 3 ч; 0 — сохранить режим.
horizon_h: 3                              эффект описан на плато 3–8 ч; для h < 3 польза не засчитывается,
                                          вред — по β_strong (объявленное правило, отдельно не проверено).
response_artifact (ежемесячно, τ ≤ t)     τ, β_τ, β_weak = 0.5·β_τ, β_strong = max(m_τ·β_τ, −1), q01/q99 T11 и F26,
                                          таблица аналогов — `response_model.fit` без изменений.
calibration (ежемесячно, месяц m, h)      q_lo = q0.05, q_hi = q0.95 остатков y_ЛИМС − (F + β·ΔT_real) по пробам с отбором
                                          в (m − 6 мес., m − 4 ч]; n ≥ 60; цель — ЛИМС ГО, точка 2.

ComposedForecast
  status: ok | forecast_unavailable | calibration_missing | action_forbidden
  baseline:  {value: F, model, fallback: bool}
  effect:    {zone: HOLD | A_SUPPORTED | B_EXTRAPOLATION | C_FORBIDDEN, mid: β_τ·ΔT,
              low: min(β_weak·ΔT, β_strong·ΔT), high: max(...), support_analogs, beta_tau, tau, reasons}
  value:     F + effect.mid
  lower:     max(0, F + effect.low + q_lo)
  upper:     F + effect.high + q_hi
  calibration: {month, horizon_h, q_lo, q_hi, n, window}

Правила
  forecast.available = false          → status forecast_unavailable; слой ничего не придумывает (как сейчас — отказ)
  ΔT = 0                              → zone HOLD; value = F; [F + q_lo, F + q_hi]; β не нужен
  zone C при ΔT ≠ 0                   → status action_forbidden; эффект не считается, план с этим действием — unknown
  zone B                              → разрешён только консервативный край (интервал уже использует weak/strong)
  нет калибровки месяца (n < 60)      → status calibration_missing; верхняя граница unknown
  слой не меняет F, trust, fallback, модель и её собственный интервал; gate проверяет upper
```

Точка встраивания в советчик (не выполнено): сейчас приток основного резервуара = верхняя граница F × множитель
сценарной модели ГО. С response layer приток на шаге плана = `upper(ΔT_плана, h)`, где ΔT — изменение уставки
температуры ГО, действующее к этому шагу; сценарный коэффициент `conversion_per_degree` для серы больше не нужен.
Условие встраивания — подтверждение смысла T11.
