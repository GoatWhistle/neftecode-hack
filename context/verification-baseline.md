## Найденные и исправленные дефекты

1. **`advise` падал на ранее обученной модели.** `runtime.gather_evidence` читал ключи
   конфигурации напрямую из `bundle["config"]`. Модель, обученная более старым конфигом,
   давала `KeyError: 'margin_trend_window_hours'` вместо решения.
   Исправление: блоки доказательств `margin` и `twins` проверяют наличие нужных ключей и
   при их отсутствии отключаются с явной причиной. Тихая подстановка значений по умолчанию
   не применяется: устаревший артефакт не должен молча выглядеть как совместимый.
2. **Мёртвые импорты в `cli.py`.** `attribution`, `batch`, `lag`, `margin`, `SupportAgent`
   импортировались и не использовались — след незавершённого подключения. Удалены.
   Сами модули сохранены: они реально вызываются из `runtime.gather_evidence`.
3. **`task/` не должен попадать в Git.** Каталог исходных данных занимает 331 МБ
   (`avt_tags.csv` 247 МБ, `242000_tags.csv` 91 МБ); условия распространения выданных
   организаторами файлов не согласованы. Добавлен в `.gitignore`; способ получения
   описывается в README на задаче T26.

## Что работает, что отключено, что не закончено

**Работает и проверено этим прогоном:** чтение CSV/XLSX с независимыми временными осями,
построение признаков по доступности, сравнение пяти методов прогноза на замороженных
хронологических периодах, отдельный детектор превышений с порогом по бюджету ложных тревог,
цикл агентов с запретом и пересчётом, синтетическое смешение по сере, журнал решений, CLI
`train` / `demo` / `advise`.

**Отключается при недостаточных данных:** блоки доказательств `margin`, `twins`,
`attribution`, `control_review` в `runtime.gather_evidence`. Каждый может отсутствовать в
решении; отсутствие теперь всегда сопровождается причиной.

**Не закончено, вынесено в задачи пула:**

- Настройки расходятся с поздними уточнениями экспертов: `lab_delay_hours` = 6 при ответе
  «до 4 часов», `horizon_hours` = 2 при горизонте 0–3 часа, `control_candidates` не
  содержит подтверждённых P8/T11/F19. — T02, T05.
- Определение эпизодов и упреждения тревог в `batch.py` / `margin.py` несогласованно. — T09.
- Модели последствий АВТ и гидроочистки отсутствуют; есть только смешение. — T10, T11.
- Смешение проверяет одну серу; T95 и цетановое число не рассчитываются. — T12.
- Запасы резервуаров, план во времени, тяжесть режима — отсутствуют. — T13, T14, T17.
- Единого модуля обязательных проверок нет: проверки встроены в `agents.py`. — T15.
- Ограничение насоса и шага доли — выдуманные параметры сценария, не оценка оборудования. — T14.
- UI и HTTP API отсутствуют. — T23.
- 30 существующих тестов покрывают базовое ядро. Исследовательские `lag.py`, `support.py`,
  `twins.py`, `attribution.py`, `batch.py`, `margin.py`, `claims.py` собственных тестов не
  имеют: их корректность этим прогоном не подтверждена. — T07, T09, T19.

## Ограничения проверки

Прогон подтверждает, что код запускается и даёт прежние числа. Он не подтверждает
правильность метрик, физическую осмысленность признаков и тем более пользу рекомендаций
на реальном заводе. Период 2026 уже просмотрен ранее и остаётся фиксированным
историческим ориентиром, а не новым слепым тестом.
