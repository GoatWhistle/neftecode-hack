## T41: live-контракт

- MakeDecision принимает явный DataRejection. Этот отказ останавливает решение до оценки
  state и поиска вариантов, сохраняет стандартную JSON-форму отказа и trace агента данных.
  GetLiveAdvice передаёт отказ snapshot, даже если state выглядит пригодным.
- ForecastBindingError принадлежит application. Локальный binder переводит ошибки привязки
  в этот контракт; use case возвращает decision=None, explanation=None, error и note.
  HTTP переводит эту ошибку в прежний 422 forecast_binding_failed.
- Inventories рассчитываются в общем use case. HTTP-представление добавляет inventories и
  sources; локальный JSON сохраняет прежние поля.
- Невалидный budget HTTP live сохраняет 422 invalid_budget.
