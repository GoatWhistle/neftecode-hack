с DDD-подходом. Каждый этап выполняется отдельным коммитом от kaifarikman, без AI-соавторов,

## Текущая задача

T35–T38 завершены: поверх Clean Architecture проект работает как набор отдельных
локальных HTTP-процессов — data, model, decision и gateway. Общими остаются доменные типы и
версионированные JSON-контракты. Прежние CLI-команды и браузерный JSON сохранены.

Общая HTTP-основа уже реализована: envelope `v1`, request ID, единые ошибки, лимиты JSON,
межсервисный timeout и `healthz`/`readyz`. Data-service выдаёт сценарии и подписанный по содержимому
snapshot; model-service проверяет его время/схему/хеш и единственный загружает bundle. Реальный
snapshot→forecast сохранил 5.88 мг/кг и верхнюю границу 9.17. После T36 проходит 769 тестов.

Decision-service принимает сценарное решение сам и собирает live advice через data/model HTTP.
Gateway-service только преобразует браузерные запросы и рисует экран. Сквозной HTTP-тест сохраняет
decision ID локального режима; полный прогон после T37 — 776 тестов.

`neftecode-stack` запускает четыре subprocess, ждёт health/readiness и завершает всю группу при
сбое или сигнале. Все процессы также имеют отдельные команды. Полный прогон: 783 теста.
Модель переобучена: fingerprint `414fa095c9c25c6dc2287548ecad7261213c243c98975a60a9c2b71a6a230556`,
выбраны `last_pak` для серы и `last_lab` для T95; advise сохранил 5.88/9.17 и `hold`.

## Что работает

Советчик оператору АВТ → гидроочистка → смешение: доступные данные → проверка доверия → прогноз →
постоянные/переходные планы → модель последствий и запасов → обязательные проверки → сравнение →
объяснение. Агенты — программные роли внутри decision-контекста; CLI и четыре сервисных процесса
используют одно ядро. Нет автоматического управления заводом; commercial_release_allowed=false.

- Сера и T95 проверены на истории; простой прогноз не побеждён. Для цетана 42 анализа, ML не заявлен.
- Сера, T95 и цетан смеси проверяются по каждой точке. Неизвестный предел T95 не наследует серный.
- Приток постепенно меняет массу и свойства запаса, а не мгновенно весь резервуар. Расход
  притока сценарный, внутри шага сначала отбор, затем смешение; T95/цетан — линейное приближение.
- Gate требует полные уставки, запасы, сетку и конечный остаток. Запрет агента исключает план.
- Feedback создаёт новые варианты; бюджет ограничен, одинаковое содержимое пропускается.
- Replay учитывает фактические остатки, рецепт, выпуск, дозу и время подтверждённых действий.
  Сохранение/продолжение воспроизводимо. Snapshot без журнала считается установившимся режимом.
- Экран показывает рецепт и управление до/после. Плохие данные останавливают прогноз заранее.
