## Что работает

Советчик оператору АВТ → гидроочистка → смешение: доступные данные → проверка доверия → прогноз →
постоянные/переходные планы → модель последствий и запасов → обязательные проверки → сравнение →
объяснение. Агенты — программные роли внутри decision-контекста; CLI и четыре сервисных процесса
используют одно ядро. Нет автоматического управления заводом; commercial_release_allowed=false.

- Сера и T95 проверены на истории; простой прогноз не побеждён. Для цетана 42 анализа, ML не заявлен.
- Сера, T95, цетан и плотность смеси проверяются по каждой точке; плотность — двусторонний предел,
  смешение по аддитивности объёмов (T50). Неизвестный предел T95 не наследует серный.
- Приток постепенно меняет массу и свойства запаса, а не мгновенно весь резервуар. Расход
  притока сценарный, внутри шага сначала отбор, затем смешение; T95/цетан — линейное приближение.
- Gate требует полные уставки, запасы, сетку и конечный остаток. Запрет агента исключает план.
- Feedback создаёт новые варианты; бюджет ограничен, одинаковое содержимое пропускается.
- Replay учитывает фактические остатки, рецепт, выпуск, дозу и время подтверждённых действий.
  Сохранение/продолжение воспроизводимо. Snapshot без журнала считается установившимся режимом.
- Экран показывает рецепт и управление до/после. Плохие данные останавливают прогноз заранее.
