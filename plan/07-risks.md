# 07. Риски

| # | Риск | Последствие | Мера |
|---|---|---|---|
| R1 | Экстракция `_search`/`release` меняет поведение legacy | Меняются решения демо и защиты | Golden sha256 + T60 до изменения; экстракция без правок логики |
| R2 | LLM «одобряет» недопустимый план | Небезопасная рекомендация | Выбор только из Gate-feasible; resolution кодом; `release` + повторный guard; adversarial тесты |
| R3 | LLM ослабляет ограничения | Выход за пределы | Закрытый словарь только ужесточающих ограничений; пределов нет в tools |
| R4 | Недетерминизм LLM | Разные решения на одном входе | Итог — всегда Gate-feasible план, выбранный `rank()` в allowed; `decision_id` по содержимому; temperature 0.2; trace для аудита; legacy остаётся эталоном |
| R5 | Сбой провайдера (timeout, 5xx, rate limit, квота) | Нет решения | Fallback на legacy; ≤1 retry только retryable; бюджет времени |
| R6 | Взрыв токенов | Расход квоты, лимиты | Shortlist ≤5, контекст ≤12K символов, результат tool ≤2.5K, ≤12 вызовов, без траекторий и сырых данных |
| R7 | Рекурсивные/бесконечные циклы агентов | Зависание, расход | Специалисты не вызывают агентов; лимиты шагов/вызовов/consults/replans/времени; forced final |
| R8 | Prompt injection через данные (названия, reasons, заметки сценария) | Смена поведения агента | Данные только в JSON-блоке DATA, обрезка; system prompt константа; allowlist; tools без FS/сети/shell; итог всё равно проходит Gate |
| R9 | Утечка ключа | Компрометация аккаунта | `Secret` redacted, ключ только в заголовке адаптера, тест на отсутствие в repr/trace/исключениях, `.env` добавлен в `.gitignore` 2026-09-16 (до этого не игнорировался; в истории git отсутствует), ключ не печатается и не передаётся субагентам |
| R10 | **Условия Z.AI Coding Plan**: использование только в поддерживаемых инструментах; нарушение → ограничение/бан (коды 1113/1313/1315) | Блокировка аккаунта пользователя | **Риск принят пользователем 2026-09-16.** Один live smoke, без повторов, остановка на quota-кодах; для эксплуатации — локальная OpenAI-compatible LLM или платный API |
| R11 | Случайное использование General API (списание баланса) | Незапланированные расходы | Default Coding Plan URL; factory отказывает для URL без `/api/coding/` без явного `ZAI_ALLOW_GENERAL_ENDPOINT=1` |
| R12 | **Противоречие offline-требованию** (закрытая сеть, Q&A 11.09; `deployment_requirements`) | Облачная LLM недоступна на заводе | С 16.09 агенты включены всегда (решение пользователя); в закрытой сети — локальная модель или явное `AGENTIC_DECISION_ENABLED=0`; legacy полностью работает offline; OpenAI-compatible адаптер указывает на локальную LLM завода через `OPENAI_BASE_URL` |
| R13 | Forced thinking GLM-5.3-Flash расходует `max_tokens` и время | `finish_reason=length`, пустой ответ; исчерпание бюджета времени | `LLM_MAX_TOKENS=6144`; `length` без tool_calls → ошибка → fallback. **Замер 2026-09-16: 10–45 с на вызов**, поэтому `AGENT_TIMEOUT_SECONDS` поднят 180 → 600, `LLM_REQUEST_TIMEOUT_SECONDS` 60 → 120 |
| R24 | Агенты включены всегда | Каждое решение (serve, scenes, screen, advise, decision-service) обращается к облачной модели: минуты ожидания, расход квоты Coding Plan, риск по условиям плана (R10) | Бюджет ≤ 12 вызовов и 600 с на решение; gateway ждёт decision 660 с; сбой модели → детерминированное решение; тесты фиксируют `AGENTIC_DECISION_ENABLED=0`; benchmark и replay остаются детерминированными |
| R23 | Специалист тратит много вызовов на инструменты и не доходит до `submit_opinion` | Мнение UNKNOWN, решение уходит в fallback | Наблюдалось в живом прогоне у ReliabilityAgent: лимит 3 вызовов, forced final на последнем; при необходимости поднимать `AGENT_SPECIALIST_MAX_CALLS` вместе с бюджетом времени |
| R14 | `tool_choice` у Z.AI только `auto` | Модель отвечает текстом вместо tool | Repair текста; forced-final сообщение; UNKNOWN/fallback |
| R15 | Агентный режим «декоративный» (одинаковый путь для всех входов) | Не выполнено требование «настоящий агент» | Tools выбирает LLM; тесты PolicyLLM показывают разные пути; live smoke показывает реальный выбор модели; честная маркировка scripted demo |
