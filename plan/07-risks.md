# 07. Риски

| # | Риск | Последствие | Мера |
|---|---|---|---|
| R1 | Экстракция `_search`/`release` меняет поведение legacy | Меняются решения демо и защиты | Golden sha256 + T60 до изменения; экстракция без правок логики |
| R2 | LLM «одобряет» недопустимый план | Небезопасная рекомендация | Выбор только из Gate-feasible; resolution кодом; `release` + независимый guard; adversarial тесты |
| R3 | LLM ослабляет ограничения | Выход за пределы | Закрытый словарь только ужесточающих ограничений; пределов нет в tools |
| R4 | Недетерминизм LLM | Разные решения на одном входе | Итог — всегда Gate-feasible план, выбранный `rank()` в allowed; `decision_id` по содержимому; temperature 0.2; trace для аудита; legacy остаётся эталоном |
| R5 | Сбой провайдера (timeout, 5xx, rate limit, квота) | Нет решения | Fallback на legacy; ≤1 retry только retryable; бюджет времени |
| R6 | Взрыв токенов | Расход квоты, лимиты | Shortlist ≤5, контекст ≤12K символов, результат tool ≤2.5K, ≤12 вызовов, без траекторий и сырых данных |
| R7 | Рекурсивные/бесконечные циклы агентов | Зависание, расход | Специалисты не вызывают агентов; лимиты шагов/вызовов/consults/replans/времени; forced final |
| R8 | Prompt injection через данные (названия, reasons, заметки сценария) | Смена поведения агента | Данные только в JSON-блоке DATA, обрезка; system prompt константа; allowlist; tools без FS/сети/shell; итог всё равно проходит Gate |
| R9 | Утечка ключа | Компрометация аккаунта | `Secret` redacted, ключ только в заголовке адаптера, тест на отсутствие в repr/trace/исключениях, `.env` в `.gitignore`, ключ не печатается и не передаётся субагентам |
| R10 | **Условия Z.AI Coding Plan**: использование только в поддерживаемых инструментах; нарушение → ограничение/бан (коды 1113/1313/1315) | Блокировка аккаунта пользователя | **Риск принят пользователем 2026-09-16.** Один live smoke, без повторов, остановка на quota-кодах; для эксплуатации — локальная OpenAI-compatible LLM или платный API |
| R11 | Случайное использование General API (списание баланса) | Незапланированные расходы | Default Coding Plan URL; factory отказывает для URL без `/api/coding/` без явного `ZAI_ALLOW_GENERAL_ENDPOINT=1` |
| R12 | **Противоречие offline-требованию** (закрытая сеть, Q&A 11.09; `deployment_requirements`) | Облачная LLM недоступна на заводе | Флаг выключен по умолчанию; legacy полностью работает offline; OpenAI-compatible адаптер указывает на локальную LLM завода через `OPENAI_BASE_URL` |
| R13 | Forced thinking GLM-5.3-Flash расходует `max_tokens` | `finish_reason=length`, пустой ответ | `LLM_MAX_TOKENS=2048`; `length` без tool_calls → ошибка → fallback |
| R14 | `tool_choice` у Z.AI только `auto` | Модель отвечает текстом вместо tool | Repair текста; forced-final сообщение; UNKNOWN/fallback |
| R15 | Агентный режим «декоративный» (одинаковый путь для всех входов) | Не выполнено требование «настоящий агент» | Tools выбирает LLM; тесты PolicyLLM показывают разные пути; live smoke показывает реальный выбор модели; честная маркировка scripted demo |
| R16 | Scripted demo выдаётся за работу LLM | Введение жюри в заблуждение | `provider="scripted"` в trace и файле; текст «детерминированная политика, не LLM» |
| R17 | Слой не даёт измеримой пользы относительно legacy | Переусложнение | Legacy остаётся default; old vs new таблица; польза заявляется только как объяснимость и дополнительные проверки, не как экономия завода |
| R18 | Нарушение правил слоёв (подстрока «http» в application, импорт composition из services) | Падение architecture tests | Размещение по 01 §3; architecture tests после каждой задачи |
| R19 | Response layer не встроен (T11/F26 не подтверждены) | Агент не видит эффект температуры по данным | Port + unavailable adapter; сценарная модель отклика доступна через evaluations; модель и β не трогаются |
| R20 | Изменение fingerprint источников (`source_manifest`) при добавлении .py | `model_service` сверяет manifest и bundle: несовпадение после переобучения | Fingerprint меняется только при `neftecode train`; существующие `artifacts/model.pkl` и `manifest.json` не пересоздаются в рамках задачи; отметить в state.md |
| R21 | `refusal.kind=agent_rejected` не отображается в UI/explain | Ошибка экрана | `explain_refusal` fallback-текст + тест Screen на agentic dict |
| R22 | Live smoke упал по локальной ошибке | Искушение повторять live | Разбор и исправление на FakeLLM/mock; повторный live только по новому поручению |
