# src/frontend

React + TypeScript + CSS. Сборка: `npm install`, затем `npm run build` → `src/frontend/dist/`.

Python отдаёт собранную статику по пути из параметра `--static` (умолчание `src/frontend/dist`).
Внутрь `src/neftecode` ни исходники, ни сборка не попадают.

Ограничение: ни одной внешней ссылки в рантайме — шрифты системные, графика инлайн-SVG.

## Как запускать экран

Основной интерактивный экран рассчитан на `uv run neftecode serve`:

```bash
cd src/frontend && npm install && npm run build
cd ../..
uv run neftecode serve
```

Этот сервер отдаёт `GET /api/options` и поток `GET /api/stream`; именно поток нужен для
показа стадий, событий агентов и итогового `ScreenPayload`. Полный
`uv run neftecode-stack` — отдельный сервисный контур для HTTP-расчёта и его gateway
не реализует `/api/stream`, поэтому собранная страница при обращении к gateway не сможет
показать live-прогресс (ответ будет 404). Для stack используйте его legacy-эндпоинт
`/api/decide` или API `/v1/*` напрямую; это не равно интерактивному экрану.

## Режимы и честность показа

- **Live** — браузер получает текущий SSE-поток от локального `serve`; участие внешней
  LLM определяется полями ответа, а не самим фактом наличия этапа «Агенты».
- **Offline** — backend-сценарии и детерминированный контур работают без внешней сети.
  Это не доказательство, что LLM была вызвана.
- **Replay** — после успешного live-прогона браузер может локально повторить записанные
  в память события с ускоренной паузой. Запись не импортируется из архива и исчезает при
  перезагрузке; replay не запускает новый расчёт.
- **Fallback / отказ** — транспортная ошибка и отказ доменного решения различаются:
  первый означает незавершённый расчёт, второй является корректным результатом ядра.

Кнопка остановки прекращает чтение потока в браузере; отдельный контракт отмены на сервере
не заявлен. Не показывайте остановку как технологический `refuse`.

## Известные ограничения текущего экрана

Начальная загрузка `/api/options` при сетевой ошибке сейчас не выставляет текст ошибки,
поэтому до повторного запроса пользователь может увидеть пустую форму. При быстрых сменах
сценария ответы запросов не имеют `AbortController`/порядкового номера: старый ответ может
перезаписать более новый выбор. Это ограничения реализации, а не обещанные свойства
воспроизводимости; перед демонстрацией дождитесь загрузки выбранного сценария и проверяйте
подпись среза в условиях запуска.
